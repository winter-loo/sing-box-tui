# Node quality panels UI prototype

Throwaway, read-only browser simulation for comparing three TUI information architectures.

Run from the repository root:

```sh
python3 -m http.server 4173 --directory prototypes/node-quality-panels
```

Open `http://127.0.0.1:4173/?variant=A`. Use the floating arrows or keyboard left/right arrows to compare variants A, B, and C.
