# Prototype verdict

The user selected **Variant A: top node-view tabs with in-place quality context**.

The production TUI should preserve the existing selector list on the left and place extensible node-view tabs above the current selector's candidate list on the right. The selected panel defines the visible candidates and automatic-selection candidate set. Full node-quality evidence remains available through the existing `i` interaction; narrow terminals must not reserve a permanent third column for details.

Variant B and Variant C were rejected as the primary information architecture. Their prototype code remains on this throwaway branch as primary-source comparison material and must not be merged into production.
