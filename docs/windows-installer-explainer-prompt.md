# Prompt for Windows Installer Commit Explainer

```text
Review the latest 4 commits and create a standalone interactive HTML tutorial.

Audience:
I know Python, but I am new to Windows scripts and PowerShell.

Please teach:
- What each commit changes, in simple “like I’m 12” language.
- The PowerShell syntax and code blocks used by the Windows installer.
- The installer’s full logic flow, step by step.

Style requirements:
- Tutorial-style, not landing-page style.
- Use Python comparisons when explaining PowerShell.
- Use clear sections, examples, checkpoints, and progressive explanations.
- Use GSAP for animations and interactions.

Output:
A rich HTML file.
```
