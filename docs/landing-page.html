capabilities

Everything power users wanted around sing-box, wired into one terminal surface.

sing-box-tui talks to the Clash-compatible controller API, keeps your local config intact, and gives you operational controls without leaving the keyboard.

↯

Selector switching that understands providers

Navigate selector groups, provider groups, and nodes in two- or three-column layouts. Selecting a node can update the child provider selector and point the parent selector at it.

ms

Async benchmarking + latency sorting

Benchmark an entire selector or a single highlighted node. Sort healthy results by latency, hide failed probes, and keep the TUI responsive while checks run.

ap

Runtime auto-pick

Apply include/exclude filters like 美国,!倍率, then let auto-pick benchmark every 30 seconds and switch only when the current node is slow, failed, or outside policy.

sub

Subscription refresh without config drift

Refresh provider subscriptions from .suburl, cache payloads, update only server node outbounds, preserve DNS/routes/inbounds, and keep a fixed backup before writes.

B

Direct-bypass editor

Edit domains, IPs, and CIDRs from the TUI. Entries are written to a local sing-box source rule-set and mirrored into OS proxy bypass lists when system proxy is enabled.

cx

Live traffic visibility

Inspect active connection totals and drill into inbound type, destination host/IP, outbound chain, and matched route rule from inside the interface.

operator workflow

From subscription URL to healthy route in a few keystrokes.

Install the binary, launch the TUI, paste a sing-box subscription URL on first run, then control nodes, filters, benchmarks, and proxy state from one cockpit.

1

Launch

Run sing-box-tui run. The first-run wizard can create .suburl or skip setup for manual configs.

2

Filter

Press / and type include/exclude rules. Use regional, provider, or pricing hints already encoded in node names.

3

Benchmark

Press b for group probes or t for the highlighted node. Results are stored in SQLite for charts and history.

4

Switch / automate

Press Space to switch manually, or a to arm auto-pick so the best healthy filtered node wins when it matters.

ops-grade details

Built for people who read logs, diff configs, and hate mystery daemons.

No magic cloud account. No opaque sync service. Just a local Rust app, local state files, explicit controller calls, and generated configs you can inspect.

Config-respecting by design

Generated and merged configs set selector/urltest interrupt_exist_connections to false, so switching nodes does not tear down existing flows. Existing connections finish on their original outbound; new traffic uses the new selection.

preserve DNS preserve routes preserve inbounds replace nodes only when asked

Cross-platform proxy toggles

Press p to toggle the OS system proxy for the detected sing-box mixed inbound. Windows uses WinINET, macOS uses networksetup, and Linux GNOME uses gsettings.

CLI escape hatches

Use selectors, status, benchmark, subscribe, subscriptions, sync, and import when you want JSON output, scripts, or CI-friendly workflows.

install.sh 
# Windows x64: install latest release + sing-box if missing
irm https://raw.githubusercontent.com/winter-loo/sing-box-tui/main/scripts/windows/install.ps1 | iex

# Start the cockpit
sing-box-tui run

# Or use CLI probes directly
sing-box-tui benchmark --match "美国,!倍率" --switch --verify
sing-box-tui status
sing-box-tui selectors --selector select
